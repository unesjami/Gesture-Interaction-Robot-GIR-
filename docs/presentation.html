GIR — Project Presentation 01
01 • Concept

What is GIR?

GIR is an interactive humanoid robot that understands selected human hand gestures through a webcam and converts them into commands for an embedded controller.

👁

Perception

Python, OpenCV and MediaPipe analyze live camera frames and identify hands, landmarks and finger states.

⚙

Action

Arduino receives high-level serial commands and coordinates servos, audio, eyes and autonomous behaviors.

04 • Gesture Control

Simple gestures, clear commands

Gesture Robot response
Right hand • 4 fingers Raise / lower right hand
Left hand • 4 fingers Raise / lower left hand
Right hand • index direction Move robot head left / center / right
Right hand • thumb + index Rotate robot body
Double clap Toggle robot state / trigger behavior
Interaction Model 05
05 • Embedded Control

Arduino turns commands into behavior

Receive
Read high-level commands from the computer over serial communication.
Interpret
Map each command to a robot behavior and manage the current state.
Move
Drive servos with smooth motion rather than abrupt position changes.
Respond
Trigger audio, eyes, sensors and introduction/autonomous behaviors.
Embedded Behavior Layer 06
06 • Motion & Safety

Designed for natural interaction

〰

Smooth Servo Motion

Easing-based movement reduces abrupt changes and creates more natural motion across the robot's joints.

🛡

Failsafe Behavior

When no hand is detected, relevant controls return toward a safe neutral behavior.

🧠

State Management

Active states prevent repeated commands and keep behavior consistent.

🔊

Multimodal Feedback

Movement, sound and visual elements work together to make the robot's responses understandable.
